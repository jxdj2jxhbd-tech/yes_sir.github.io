基础知识梳理与常见漏洞类型总结

一、学习目标
通过本次学习，系统掌握 CTF Pwn（二进制漏洞挖掘与利用）方向的核心概念，了解常见漏洞类型及其基本原理，为后续实战练习打下坚实基础。
Pwn 题型的典型流程如下：
给定一个编译好的二进制程序（Windows 的 EXE 或 Linux 的 ELF）
选手通过逆向分析和调试寻找漏洞
编写利用代码（Exploit）
通过远程代码执行（RCE）达到攻击效果
获取目标机器的 shell，夺取 flag
二、Pwn 类题目常见漏洞类型
Pwn 题目涉及的漏洞类型多样，以下是五类最核心、最常见的漏洞：
▶ 2.1 栈溢出（Stack Overflow）
原理：程序在栈上分配固定大小的缓冲区（如 char buf[10]），但未限制输入长度，超长数据覆盖了栈上相邻的寄存器、返回地址等关键数据，从而控制程序执行流。
典型有漏洞代码示例：
void vulnerable_function() {
char buf[10];
scanf(“%s”, buf); // 无边界检查，存在溢出风险
}
利用步骤：
输入超长字符串，造成存储越界
覆盖返回地址（Return Address）
将返回地址指向预先填充的 Shellcode 内存空间
相关安全机制与绕过：DEP/NX（数据执行保护）、Stack Canary（栈保护）、ASLR（地址空间布局随机化），对应绕过技术包括 ROP（返回导向编程）、Ret2libc、Return to dl-resolve 等。
▶ 2.2 堆溢出（Heap Overflow）
原理：堆上的内存由堆管理器动态分配。当向堆块写入超长数据时，会覆盖下一个相邻堆块的块首（Chunk Header / Metadata），导致堆管理器在后续分配或释放操作时按照被伪造的元数据进行操作，从而实现任意内存写入。
堆溢出是 CTF Pwn 中非常高频的考点，衍生出 unlink 攻击、Fastbin Attack、House of 系列等高级利用手法。
▶ 2.3 整数溢出（Integer Overflow）
原理：当整数运算结果超出该数据类型所能表示的范围时，会发生回绕（wrap-around）。攻击者可利用整数溢出绕过长度检查（如绕过 size <= 0 的检查），进而触发后续的缓冲区溢出等漏洞。
▶ 2.4 格式化字符串漏洞（Format String Vulnerability）
原理：printf 系列函数中的格式化字符串（如 “%s”, “%x”, “%n”）会从栈上读取参数。若程序员直接将用户输入作为格式化字符串传入，攻击者可通过构造特殊格式说明符实现任意内存读写。
常见格式说明符：
%d —— 十进制整数
%s —— 字符串（从内存地址读取）
%x —— 十六进制
%p —— 指针地址
%n —— 将已输出字符数写入指定内存地址（可造成任意内存写入）
典型有漏洞代码示例：
#include <stdio.h>
int main() {
char *thing = “car”;
printf(“This is %s\n”, thing); // 正常
printf(“This is %s\n”); // 漏洞：无参数但有格式符
return 0;
}
▶ 2.5 释放后重用（Use After Free，UAF）
原理：内存被释放后，其指针未被置空，若程序后续再次使用该指针访问已释放的内存块，可导致任意代码执行或信息泄露。UAF 是现代软件中极为常见的高危漏洞类型。
三、典型安全机制与绕过思路
DEP/NX（数据执行保护）：禁止在数据页（如堆、栈）执行代码，无法直接注入 Shellcode。绕过思路包括 ROP（返回导向编程）、Ret2libc（返回到 libc 中的函数）等。
Stack Canary（栈金丝雀）：在栈帧返回地址前插入一段随机值（canary），函数返回前检查其是否被破坏。若溢出覆盖了 canary，程序将调用 __check_security_cookie 终止。绕过方式包括泄露 canary 值后在溢出时完整覆盖、爆破 canary 等。
ASLR（地址空间布局随机化）：每次运行程序时随机化内存布局（栈、堆、共享库的基地址），增加攻击难度。需要通过信息泄露（Format String 等）获取目标地址后再构造利用。
四、学习总结
本次学习围绕 Pwn 方向的入门知识展开，涵盖了以下核心内容：
理解了 Pwn 的本质——通过逆向与漏洞利用获取目标程序的控制权
系统学习了五类最常见的漏洞：栈溢出、堆溢出、整数溢出、格式化字符串、UAF
理解了 DEP/NX、Stack Canary、ASLR 等典型安全机制及其绕过思路
认识到扎实的基础理论知识是成功解题的前提，Shellcode 编写、ROP 链构造等需要进一步深入学习
