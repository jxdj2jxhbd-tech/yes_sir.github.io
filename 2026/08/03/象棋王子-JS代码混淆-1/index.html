📌 题目信息

项目 内容
题目来源 VNCTF 2023
题目名称 象棋王子
题目类型 Web 签到题
核心考点 前端 JavaScript 代码审计、JSFuck 混淆解密

靶机地址：http://0991b3125e2a0cf2c0f2b9e2.http-ctf2.dasctf.com/(格式参考）

🎯 解题过程

第一步：打开页面

打开靶机地址，可以看到一个象棋棋盘页面，标题“多看一眼就会爆炸，赢了就送Flag～”

但是——棋盘点不了，痛失下棋机会。这说明题目不是让玩家通过下棋赢的。

第二步：查看页面源代码

遇事不决看源码，使用 Ctrl+U 查看页面源代码。

浏览完整段 HTML 后，发现页面结构本身应该没有什么问题，没有 XSS 注入点（按钮点击无反应，URL也没有参数），也没有路径遍历漏洞。

第三步：锁定外部 JS 文件

HTML 中引用了 5 个外部 JS 文件：

既然 HTML 没问题，那漏洞很可能藏在这些 JS 文件里。

挨个访问这些 JS 文件后，在 play.js 中发现了关键线索：

访问地址：http://0991b3125e2a0cf2c0f2b9e2.http-ctf2.dasctf.com/js/play.js

第四步：发现混淆代码

在 play.js 中找到了这个函数：

逻辑是：

· 如果 my === 1 → 执行那串奇怪符号
· 否则 → 弹窗 “很遗憾，你输了！”

第五步：识别 JSFuck

仔细观察那串奇怪符号：

[][(![]+[])[+[]]+(![]+[])[!+[]+!+[]]+(![]+[])[+!+[]]+(!![]+[])[+[]]]…

特征非常明显：
只有 !+ 六种字符 没有字母，没有数字
完全不可读 肉眼无法理解其含义

根据这些特征可以判断，这是 JSFuck——即利用 JavaScript 隐式类型转换、仅用六个符号就能写出任意代码的编码方式。

第六步：解码获取 Flag

判断出是 JSFuck 后
本来想用 play.showWin(1) 直接调函数触发，结果控制台报错 Uncaught TypeError: play.showWin is not a function，应该是作用域的问题 [^1]。
复制这段编码丢给控制台，flag弹出

🔗 从这道题延伸的思考

OK，虽然得到flag，但是我对jsfuck的了解貌似仅限于可以解码。找到两篇文章：

· https://mp.weixin.qq.com/s/JylcrDciJLsDHusugPthQA
· https://github.com/aemkei/jsfuck

大概了解原理，没有完全看懂。

上面这个题显然不属于XSS攻击，不过第一篇文章仍然提供启发，也许可以用JSFuck把 alert 编码避免WAF拦截。不过没有找到类似的题，DeepSeek帮我找的Security Fest 2016 XSS 2，虽然能看到wp，即：

使用 jsfuck encode js，urlencode

=> urlencode后得到一段编码（省略）
